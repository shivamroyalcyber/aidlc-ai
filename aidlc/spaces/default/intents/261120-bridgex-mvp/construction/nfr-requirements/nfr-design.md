# NFR Requirements and NFR Design

**Stages**: 3.2 NFR Requirements and 3.3 NFR Design, run once for all units (Minimal depth).
Requirement IDs come from [requirements.md](../../inception/requirements-analysis/requirements.md).

| NFR | Design measure | Where | Verified by |
|---|---|---|---|
| NFR-01 API key | `crypto.timingSafeEqual` on SHA-256 digests of both keys | `src/gateway/auth.ts` | `auth.test.ts` |
| NFR-01 Secrets | Client key and downstream credentials generated by CDK in Secrets Manager, read at runtime and cached for 5 minutes | `infra/`, `src/gateway/secrets.ts` | `cdk synth` review; no secret values in the repo |
| NFR-01 Log masking | Values of `sensitive` fields, the WS-Security password and the Bearer token are replaced before a record is stored | `src/transform/mask.ts`, `pipeline.ts` | `pipeline.test.ts` "never stores secrets or full account numbers" |
| NFR-01 XML attacks | Reject `<!DOCTYPE` and `<!ENTITY`; parser does not expand entities; 64 KB limit | `src/transform/xml.ts` | `xml.test.ts` |
| NFR-01 XML injection | Builder escapes `&`, `<`, `>`, quotes in values | `src/transform/xml.ts` | `soap.test.ts` |
| NFR-01 Least privilege | Each Lambda gets only its table, its secrets and (gateway) one Bedrock model | `infra/lib/bridgex-stack.ts` | `cdk synth` IAM review |
| NFR-01 Edge | HTTPS only; S3 private with OAC; HTTP API throttled to 20 rps / 50 burst; CORS limited to the dashboard origin and localhost | `infra/` | Deployed config |
| NFR-02 Overhead | Integration documents loaded once per container; secrets cached; AWS SDK clients reused; arm64 | `src/gateway/` | `x-bridgex-latency-ms` vs downstream latency in the request log |
| NFR-03 Timeouts and retries | `AbortController` timeout per attempt; backoff `base × 2^(n-1)` plus up to 50% jitter; at most 3 attempts | `src/gateway/retry.ts` | `retry.test.ts`, `pipeline.test.ts` |
| NFR-04 Observability | One JSON log line per request; EMF metrics `Requests`, `Failures`, `Retries`, `LatencyMs` by `Integration`; CloudWatch dashboard; alarm on failures | `src/gateway/metrics.ts`, `infra/` | Deployed dashboard |
| NFR-05 Cost | On-demand DynamoDB; 7-day TTL; 1-week log retention; no NAT or VPC | `infra/` | Stack review |
| NFR-06 Maintainability | Integration documents validated at load and in tests; strict TypeScript; golden-file tests | `src/config/` | `registry.test.ts`, `npm run typecheck` |
| NFR-07 Portability | `scripts/local-server.ts` wires the same handlers with in-memory stores | `scripts/` | Manual run |
